# Funcionalidades Excluidas — Plan Pro / Futuro

Estas características están fuera del alcance del MVP Starter (Nexo v1) y se incorporarán en versiones posteriores de la plataforma.

| Funcionalidad | Descripción |
| --- | --- |
| Canal web | Chat embebido en sitio web del restaurante |
| Pedidos agendados | Reservar pedidos para una hora/fecha futura |
| Recuperador de ventas | Seguimiento automático a conversaciones abandonadas |
| Multi-estación | Múltiples dispositivos de cocina con asignación de estaciones |
| Impresión ESC/POS | Impresión directa de comandas en impresoras de punto de venta |
| Múltiples métodos de pago | Efectivo, PSE, tarjeta presencial, Nequi, etc. |
| Movimientos de dinero | Caja, cierres de turno, conciliación de ingresos |
| Analítica | Dashboard con métricas de ventas, productos más pedidos, horarios pico |
| Reseñas | Solicitar y gestionar reseñas post-pedido |
| Deploy Railway | Despliegue del backend en Railway con PostgreSQL gestionado |
| Multi-tenancy | Plataforma SaaS con múltiples restaurantes aislados bajo un solo backend |
